# Roadmap

This roadmap is intentionally lightweight.

## Near term

- improve public-facing documentation
- expand shell composition patterns
- harden template deployment workflows
- add stronger examples of downstream usage

## Medium term

- broaden library namespaces where they prove useful
- improve testing and evaluation coverage
- publish clearer recipes for common project setups

## Longer term

- become the shared Nix foundation for Cole-Bassed Solutions projects
- support a repeatable project bootstrap path across multiple repositories
- mature into a dependable internal and public open-source base
