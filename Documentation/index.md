## Repository map

- `flake.nix` — flake entrypoint
- `default.nix` — importable entrypoint
- `libraries/` — reusable Nix library modules
- `environment/` — dev shell definitions
- `templates/` — template deployment helpers and scaffold files

## Intended audience

This documentation is for:

- maintainers of qunix
- contributors extending the library
- downstream projects that want to consume the library or shell patterns
